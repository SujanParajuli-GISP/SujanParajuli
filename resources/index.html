    Resources

    A curated library of GIS & Remote Sensing data sources, tools, libraries, courses and tutorials. Compiled from study notes and saved posts, with every link pointing to the official source (data provider, documentation or course home) rather than to any social-media post.

    How to use this page

    • The Data sections are tables: Data · Uses · Link · Output format.
    • The Tools, Libraries, Learning sections are annotated link lists.
    • Availability, resolution and licensing change over time — always confirm on the provider's site before using a dataset in production.

    11. Desktop & web GIS software

    • QGIS — free, open-source desktop GIS; the standard companion to ArcGIS Pro.
    • ArcGIS Online — Esri's cloud Web GIS; feature-rich, built for organisations and non-programmers.
    • CARTO — cloud-native spatial analytics on PostgreSQL/PostGIS; strong for developers, usable without code.
    • Mango Map — simple no-code web-map publishing.
    • GIS Cloud — desktop-like web GIS with mobile data collection.
    • Mapbox — developer platform for fast, highly customised vector maps.

    LiDAR & point-cloud tools

    • CloudCompare — open-source 3D point-cloud and mesh processing.
    • WhiteboxTools / Whitebox GAT — 500+ geoprocessing tools for terrain, hydrology and lidar.
    • Orfeo Toolbox (OTB) — open-source remote-sensing image processing, including lidar support.

    Network / graph visualisation

    • Gephi · VOSviewer · Cytoscape · Kumu · NodeXL · Graphia · Graphistry · SocNetV

    Popular QGIS plugins

    QuickMapServices, Semi-Automatic Classification Plugin, qgis2web, Lat Lon Tools, Profile Tool, mmqgis, Qgis2threejs, LAStools, QuickOSM, GeoCoding, QTiles — all installable from the official plugin repository: https://plugins.qgis.org/

    13. Learning — courses

    • Introduction to GIS Programming (GEOG 312) — Qiusheng Wu, University of Tennessee; Python from basics to geospatial workflows (free notebooks + video).
    • Spatial Data Management (GEOG 414) — Qiusheng Wu; DuckDB, PostGIS, GeoPandas, Google Earth Engine, PMTiles.
    • Spatial Data Management with DuckDB — companion book (Python).
    • Introduction to GIS Programming — companion book (Python).
    • GEOG 486: Cartography and Visualization — Penn State open courseware; cartographic design, thematic and multiscale web mapping.
    • Automating GIS Processes — University of Helsinki; geospatial analysis with GeoPandas & friends.
    • Introduction to Python for Geographic Data Analysis — University of Helsinki open textbook.
    • NASA ARSET — free applied remote-sensing trainings, introductory to advanced (SAR, flood, air quality, land cover, disasters).
    • Analyzing US Census Data — Kyle Walker; methods, maps and models in R.
    • Geographic Data Science with Python — Rey, Arribas-Bel & Wolf; open textbook.
    • Spatial Thoughts / courses.spatialthoughts.com — Ujaval Gandhi; QGIS, GEE, Python full courses.
    • Software Carpentry — foundational shell, Git and Python lessons.
    • CS50x — Harvard's introduction to computer science.

    LiDAR-specific courses

    • Mastering LiDAR Data Processing — ROCK Academy; point clouds, DEMs, classification.
    • Introduction to Lidar — NOAA Digital Coast; short interactive modules.
    • UAS-Based Mapping & Laser Scanning — Purdue University; drone-lidar workflows.
    • Lidar in GIS (GEOG 5525) — University of North Texas course notes.
