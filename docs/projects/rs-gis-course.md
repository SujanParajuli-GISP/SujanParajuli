# Remote Sensing with Python — a Three-Course Program

*An open, self-paced curriculum from Python fundamentals to cloud-native remote sensing and machine learning.*

`Python` `Google Earth Engine` `Jupyter` `MkDocs` `Machine learning` `Google Colab`

## Overview

A complete, teachable curriculum that takes a learner from first lines of Python to
large-scale remote sensing and machine learning with Google Earth Engine. Every unit ships
lecture slides with a read-aloud transcript, hands-on Colab labs, a written exercise, and a
short guide on using AI tools productively for that topic.

## The three courses

| # | Course | Units |
|---|--------|-------|
| 1 | **Python Foundations for Geospatial Analysis** | GIS metadata and geospatial data · Python programming basics · Geospatial Python libraries |
| 2 | **Remote Sensing & Google Earth Engine** | Remote sensing fundamentals · Vector, raster and spectral indices · GEE for remote sensing |
| 3 | **Advanced Cloud Remote Sensing with GEE & Python** | GEE–Python fundamentals and preprocessing · Time series and ML preparation · Advanced classification and ecological applications |

## By the numbers

- 3 courses × 3 units, with 24 lesson pages and 9 written exercises
- 60 lecture decks with per-slide transcripts
- 20 Colab-ready lab notebooks, from DEM downloads to deforestation and land-cover change in Nepal
- A cross-course guided project
