# GIS Project Examples & Tutorials

*Open-source Python recreations of ArcGIS ModelBuilder labs.*

`Python` `GeoPandas` `Rasterio` `Folium` `Jupyter` `Google Colab`

## Overview

Seven notebooks rebuild, tool for tool, classic ArcGIS ModelBuilder workflows — suitability,
fuzzy overlay, movement, hydrology, network tracing and location-allocation — using only free
tools. **No ArcGIS licence, Spatial Analyst extension or manual downloads are needed.**

Each notebook runs top-to-bottom in Google Colab, fetches its inputs from open services
(USGS, OpenStreetMap, WorldPop and others), explains the GIS theory, maps every ArcGIS tool to
its open-source equivalent, logs each processing step, and ends with an interactive web map.

## Activities

| Activity | Topic |
|----------|-------|
| 2 | Habitat suitability modelling — mountain lion and elk, Black Hills (SD/WY) |
| 3 | Weighted overlay for housing-site suitability in Glendale, CA, and a Boolean vs. weighted comparison for elk habitat |
| 4 | Fuzzy membership and fuzzy overlay — pronghorn winter habitat in Utah and a wildfire-risk assessment of Nepal |
| 5 | Movement modelling — ambulance routing in Kathmandu, anisotropic wildfire spread in Idaho, least-cost trekking route to Machhapuchhre Base Camp |
| 6 | Hydrologic modelling — SCS/NRCS Curve Number grid and storm runoff, Black Hills National Forest |
| 8 | Utility network tracing — flags, barriers and valves on a synthetic network |
| 9 | Location-allocation (maximise attendance / market share) in San Francisco, plus a Huff gravity model for store siting in Kathmandu |
