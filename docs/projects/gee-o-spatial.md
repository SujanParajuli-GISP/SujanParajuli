## Overview

I designed and built the website for **GEE-O-Spatial Solutions Company Inc.**, a geospatial
company offering consulting, professional training and cloud software. The site is static,
fast and free to host, and deploys automatically on every push.

## Site structure

- **Home** — the company story and a clear call to action.
- **Services**
    - *Consulting* — geospatial strategy, spatial analysis and modelling, GIS implementation,
      data quality assessment, location analytics.
    - *Training* — GIS fundamentals, geoprocessing, web mapping, remote sensing, geospatial
      data science and machine learning.
    - *SaaS* — data management, real-time monitoring, spatial BI dashboards, LiDAR digital
      twins, Survey123 forms, environmental-justice mapping and SAR applications.
- **How to get started** and **Contact**.

## Build

- Content in Markdown with the Material for MkDocs theme and custom CSS.
- A GitHub Actions workflow builds and publishes to GitHub Pages on every push to `main`.
